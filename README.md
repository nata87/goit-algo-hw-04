#  Домашнє завдання №3: Алгоритми сортування

## 📂 Структура завдання

Цей проєкт містить реалізації та емпіричне порівняння трьох алгоритмів сортування:

-  `merge_sort` — сортування злиттям 
-  `insertion_sort` — сортування вставками 
-  `sorted()` — Timsort (вбудований алгоритм Python)

---

##  Опис

**Мета завдання** — перевірити на практиці ефективність алгоритмів сортування та порівняти їх швидкодію на великих наборах даних за допомогою модуля `timeit`.

---

### Запуск

```bash
python benchmark.py
```

---

##  Висновки

###  Масив з **10 000** елементів:

- **Merge Sort**: ~0.22 сек
- **Insertion Sort**: ~168 сек
- **Timsort (sorted)**: ~0.001 сек

###  Масив зі **100 000** елементів:

- **Merge Sort**: ~0.21 сек
- **Insertion Sort**: ~170 сек
- **Timsort (sorted)**: ~0.0012 сек

-  **Timsort** є найбільш ефективним серед трьох, оскільки:
  - адаптивний,
  - поєднує Insertion Sort (для коротких ділянок) і Merge Sort (для злиття),
  - використовується в Python за замовчуванням у `sorted()` та `.sort()`.

-  **Merge Sort** працює добре і стабільно (O(n log n)), але повільніший за Timsort, бо не має адаптивності.

-  **Insertion Sort** дуже повільний на великих масивах, що підтверджує його теоретичну складність `O(n²)` — **170 секунд на 100К елементів!**
